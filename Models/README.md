## How to Run

Before training any models, run the data preprocessing script:

- [`1.data_process(dnn,cnn,resnet).R`](1.data_process(dnn,cnn,resnet).R)  
  (Data processing script. This step prepares the dataset for DNN, CNN, and ResNet models.)

After running the preprocessing, go to the corresponding model folder to train each model:

- [`Models/dnn/`](Models/dnn/) — Deep Neural Network (DNN)  
- [`Models/cnn/`](Models/cnn/) — Convolutional Neural Network (CNN)  
- [`Models/resnet/`](Models/resnet/) — Residual Network (ResNet)  
- [`Models/rnn/`](Models/rnn/) — Recurrent Neural Network (RNN)
